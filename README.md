# walkthroughs

Replayable engineering walkthroughs: an unfamiliar requirement taken through
design, implementation, failure diagnosis, and verification - with my normal
AI tooling, exactly as I work. Every output is pasted from the actual run;
failures are kept, not cleaned up.

Why these exist: two independent reviewers of my portfolio said the most
valuable missing evidence was watching the method work on something
unfamiliar - not the finished artefact, the path. These are that path,
written down, replayable from the files.
